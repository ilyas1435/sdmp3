# sdmp3 v1.10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate search into the source browser, add server-side auto-spoof after every copy, calm/recolor the themes and redesign settings with dropdowns and SVG icons, and prove that copying survives a closed browser.

**Architecture:** All page CSS/HTML/JS stays in the single inline `<script>` of `project.py`; a shared row renderer serves browsing and search. `auto_spoof` is an additive v2 setting consumed inside the existing single copy worker after verification, so it works with no browser. Themes stay derived in `sdmp3_themes.py`. No copy-engine ordering or concurrency change.

**Tech Stack:** Python 3 / Flask on Termux, plain JS, Jinja, WCAG contrast module, jsdom 31 harness, Node 24.

**Spec:** `docs/superpowers/specs/2026-11-17-sdmp3-v1.10-design.md`

## Global Constraints

- Single copy writer, DFS pre-order + `natural_sort_key`; never add parallel copies, `plan_transfer()` changes or per-file `fsync`.
- `project.py` uses a **plain** `HTML_TEMPLATE` string: double `\\` in embedded JS, exactly one `<script>` block. `node --check` on the rendered script is a hard gate.
- Every `font-size` is `calc(Npx * var(--font-scale))`; no colour literals outside `sdmp3_themes.py`; no remote assets; no cache header on `/`.
- Preserve existing ids: `selectedCount`, `barSize`, `barEta`, `jocStart`, `jocMp3ToDest`, `settingsPaneIndex`, `custom_source_path`, `custom_dest_path`, `#treeContainer`, `#searchInput`, four settings tabs.
- `sdmp3_state.py` v2 settings are additive; old `settings.json` files must still load; its self-test asserts exact dicts.
- Verify with: `python -m py_compile project.py sdmp3_cli.py sdmp3_themes.py sdmp3_state.py sdmp3_groups.py sdmp3_fonts.py fetch_fonts.py`, `bash -n install.sh`, four module self-tests, render→`node --check`, then `node test_ui.js` and `python test_backend.py` in `$TMPDIR/uitest/`.
- Harness files are throwaway and stay outside the checkout (`$TMPDIR/uitest/`); regenerate `page.html`/`app.js` from `GET /` before each jsdom run.

## Review Focus

1. **Spooling while Chrome is closed** — copy must finish with zero polls; pinned by Task 5's no-polling backend test that starts a transfer, closes the "client", sleeps, and asserts `status == 'done'`.
2. **Auto-spoof against protected/source paths** — must skip selected sources, protected dirs and symlinks; pinned by Task 3's `spoof_tree()` test with a source file, a protected path and a symlink under the destination.
3. **Search view after rename/delete** — must re-run the last search, not reload the directory; pinned by Task 2's jsdom test that renames a result row and asserts the search view is still active.
4. **Palette edits breaking contrast** — every theme must pass at import; pinned by Task 4's `python sdmp3_themes.py` gate plus backend assert of 16 themes × 66 tokens.
5. **Settings partial POST / dropdown seeding** — a font POST must not reset `auto_spoof`, and selects must show the saved ids; pinned by Task 1's backend POST test and Task 4's jsdom select assertions.
